
# OpenSees Source Code for Response Sensitivity Analysis

This repository contains a modified version of the **OpenSees source code** that supports **response sensitivity analysis based on the Direct Differentiation Method (DDM)**.

## Features

- Supports response sensitivity analysis using the **Direct Differentiation Method (DDM)**.
- Suitable for research and numerical studies involving structural response sensitivity analysis in OpenSees.

## Compilation

The source code can be compiled on Windows using:
- Microsoft Visual Studio 2017 or later

## Examples

Demonstration examples for response sensitivity analysis can be found on the OpenSees Wiki:

https://opensees.berkeley.edu/wiki/index.php?title=Demonstration_Examples:

These examples can be used to test and understand the sensitivity analysis capabilities implemented in this version of OpenSees.
